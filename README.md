Activity Description

This activity introduces the fundamentals of HTML, CSS, Bootstrap, JavaScript, and jQuery through a stack simulator starter project.

The activity involves exploring the starter files, observing the webpage interface, completing a reading activity, and preparing for a demonstration. It helps develop an understanding of how these web technologies work together to create interactive web applications.

Files
index.html — Webpage structure
style.css — Webpage styling
stack.js — JavaScript logic and interactions
Purpose

To become familiar with the starter project and understand the roles of different web technologies before the demonstration.
